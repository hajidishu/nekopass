# 支付接口

- `driver.go`：适配器契约、接口字段描述、注册表。
- `epay/`：EPay V1 的下单和回调验签。
- 支付方式、订单和余额事务由 `internal/control/payments.go` 管理。

扩展接口时新增子目录，实现 `payment.Driver`，然后在 `control.New` 的注册表中加入适配器。后台表单根据 `Definition().Fields` 自动生成；同一适配器可对应任意数量的支付方式。

`Reference` 只提取订单引用，不能修改订单。`Verify` 必须验证签名、商户和付款成功状态，返回金额及平台交易号。适配器不直接修改余额；主控统一核对金额、锁定钱包、处理重复通知并记录账目。

订单会先提交，再调用 `Create`，避免提前通知找不到订单。网络下单必须遵守传入的 context，并使用 `Order.Number` 作为商户订单号及接口幂等标识；超时重试不会生成新订单号。

订单保存接口配置快照。公开订单、钱包接口不得返回该快照或商户密钥。
