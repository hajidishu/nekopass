# 用户与套餐

## 创建和分配

在「套餐管理」创建套餐，设置名称、说明、初始流量、带宽、规则数、连接数、IP 限制、节点组和售价。套餐只提供初始资源，不会随编辑自动覆盖已有用户。

各付款周期独立定价：售价留空表示不出售该周期，`0` 表示免费。每用户购买上限包含此套餐的所有成功购买、续费和免费订单，留空不限制。

在「用户管理」创建或编辑用户，选择套餐并保存；管理员自己的账号也需要套餐才能创建转发规则。

## 个人资源

管理员可直接修改单个用户的总流量、已用流量、每节点带宽、规则数、连接数、活跃 IP 数、每规则限制、节点组和到期时间。

- 资源限制留空表示不限制；总流量填 `0` 表示零额度。
- 到期时间留空表示永不到期，但账号和套餐仍需处于启用状态。
- 管理员更换套餐时复制初始限制，已用流量保留；需要归零时明确填写 `0`。
- 用户通过商城续费同套餐保留个人设置；更换套餐重新复制初始资源并重置流量。

带宽按同一用户在同一入口节点的双向业务数据合计限制，不同节点分别限速。IP 限制统计活跃客户端地址；连接数和每规则限制在各自范围生效。

## 节点权限

以用户当前「允许使用的节点组」为准。分配套餐时复制其初始授权，之后可单独修改；直转需要入口权限，中转需要入口和出口两端权限。

未选择节点组时没有节点权限。账号、套餐、节点或节点组停用，额度耗尽或到期，都可能使规则暂停。

## 其他操作

「充值」为用户增加余额并记录管理员和备注；「管理规则」进入该用户的规则页；「查询订单」按用户 ID 筛选其全部订单。个人邀请返利设置见 [注册与邀请](./account.md#邀请返利)。
