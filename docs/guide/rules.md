# 转发规则

在「转发规则」添加规则，选择入口、出口，填写监听端口与目标地址，保存并启用。监听端口留空会自动分配。

目标一行一个，支持域名、IPv4、IPv6：

```text
example.com:443
192.0.2.10:25565
[2001:db8::10]:443
```

客户端连接规则显示的入口地址与端口。直转时选择「不使用隧道，直接转发」；使用出口见 [节点中转](./tunnel.md)。

规则支持分组、复制、批量启停和 JSON 导入导出；每个账号只管理自己的规则，管理员在「用户管理」查看其他用户的规则。

## 导入与导出

默认导出 nyanpass 兼容格式，一行一个 JSON：

```json
{"dest":["example.com:443"],"listen_port":9122,"name":"示例","proxy_protocol":3}
```

导入时粘贴内容或选择文件，再选择入口、出口和分组。端口 `0` 表示随机分配，也可以勾选「重新随机分配监听端口」。最多 500 条，失败时整批回滚。

`proxy_protocol`：省略或 `0` 为关闭，`1` 为发送 v1 TCP，`3` 为发送 v2 TCP；`2` 按 v2 TCP 导入，当前不支持 UDP。`accept_proxy_protocol: 1` 开启接收，需要填写信任代理网段并升级入口节点到 v0.12.1 或更新版本。

兼容格式不包含节点、分组、启停状态和接收版本限制。需要保留全部配置时，导出选择「Nekopass 完整备份」；旧版备份仍可导入。

## 账号与额度

管理员创建用户并分配套餐，套餐仅提供初始额度、限速和节点组。管理员可在「用户管理 → 编辑」调整个人流量额度、已用流量、带宽、IP、连接数、规则上限、节点组和到期时间；修改套餐不覆盖已有用户。管理员自己的账号同样需要套餐。限制数值留空表示不限制；套餐售价留空表示不出售，`0` 表示免费。商城使用余额购买，充值目前由管理员操作。

流量与带宽按双向业务数据合计；同一用户在同一入口节点共享带宽上限，不同节点分别限速。额度耗尽或套餐到期后暂停转发。

同套餐续费保留个人资源设置；更换套餐复制新套餐初始设置。商城周期套餐每月重置流量。提前续费立即重置，放弃当前周期剩余时间，保留后续已付费时长；以购买确认框中的日期为准。
