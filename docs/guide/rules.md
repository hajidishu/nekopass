# 转发规则

在「转发规则」添加规则，选择入口、出口，填写监听端口与目标地址，保存并启用。监听端口留空会自动分配。

目标一行一个，支持域名、IPv4、IPv6：

```text
example.com:443
192.0.2.10:25565
[2001:db8::10]:443
```

客户端连接规则显示的入口地址与端口。直转时选择「不使用隧道，直接转发」；使用出口见 [节点中转](./tunnel.md)。

规则支持分组、复制、批量启停和 JSON 导入导出；每个账号只管理自己的规则，管理员在「用户管理」查看其他用户的规则。

## 账号与额度

管理员创建用户并分配套餐，管理员自己的账号同样需要套餐。限制数值留空表示不限制；套餐售价留空表示不出售，`0` 表示免费。商城使用余额购买，充值目前由管理员操作。

流量与带宽按双向业务数据合计；同一用户在同一入口节点共享带宽上限，不同节点分别限速。额度耗尽或套餐到期后暂停转发。

商城周期套餐每月重置流量。提前续费立即重置，放弃当前周期剩余时间，保留后续已付费时长；以购买确认框中的日期为准。
