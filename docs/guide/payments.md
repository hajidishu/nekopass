# 支付方式

支付功能需要主控 v0.15.1 或以上，节点无需为此功能升级。

在「管理后台 → 支付方式」添加支付方式，填写用户看到的名称，再选择支付接口。可创建多个方式，同一接口可使用不同商户配置。

## EPay

首版支持 EPay V1（MD5），配置如下：

| 配置 | 用途 |
| --- | --- |
| URL | 易支付地址，例如 `https://pay.example.com/`，也支持完整 `submit.php` 地址。 |
| PID | 商户 ID。 |
| KEY | 商户密钥。 |
| TYPE | 支付类型，如 `alipay`、`wxpay`、`qqpay`；留空跳转收银台。 |
| 排序 | 数值较小的方式优先显示。 |
| 启用 | 停用后不再提供新的充值订单。 |

「系统设置」中的面板地址必须能被支付服务器从公网访问。通知地址和返回地址由面板自动生成，无需手填。

该地址应填写实际面板域名和外部端口，不是节点 gRPC 地址。使用 Nginx HTTPS 时填 HTTPS 地址；反向代理在其他机器上还需配置主控信任该代理，见 [反向代理](./proxy.md)。

用户在商城选择支付方式充值，余额到账后购买套餐。待支付订单可在「我的订单」继续支付；浏览器返回不代表到账，以付款通知确认结果为准。

修改或删除支付方式后，已有订单仍使用创建时的配置。更换商户密钥前请处理未完成订单。
