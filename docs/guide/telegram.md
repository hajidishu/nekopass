# Telegram Bot

## 配置

在「系统设置 → Telegram Bot」填写以下内容，打开「启用 Telegram Bot」并保存：

| 配置项 | 用途 |
| --- | --- |
| 启用 Telegram Bot | 控制机器人查询和自动通知；关闭后保留配置 |
| Bot 密钥 | 在 [BotFather](https://t.me/BotFather) 创建机器人后获得的 Token |
| 管理员 Telegram 用户 ID | 每行一个数字 ID，仅这些账号可在私聊中查询面板和节点 |
| 通知目标 Chat ID | 每行一个群组或用户 ID，接收 IP / DDNS 消息；留空不发送通知 |
| IP 更换统计周期 | 默认近 7 天，可设置 1–90 天 |

先私聊机器人发送 `/start`，权限提示中会显示自己的用户 ID，将它填入管理员列表。群组先加入机器人，再发送 `/start`，提示中会显示群组 Chat ID。私聊通知接收人也先向机器人发送一次 `/start`。

## 测试消息

填写密钥和通知目标后，点击「发送测试消息」。使用当前输入，无需先保存或启用 Bot；每个目标收到自己的 Chat ID、聊天类型和测试时间，面板显示发送结果。

关闭 Bot 后停止查询和自动通知，重新启用只发送之后的新通知。升级前已配置密钥的机器人会保留启用状态。

## 面板和节点

管理员私聊发送 `/start`，显示面板版本、用户与规则数量、节点在线数量，以及面板机器的 CPU、内存、磁盘、网络速率、连接数和负载。

点击「节点信息」查看节点探针，每页两个节点，使用上一页、下一页翻页。消息显示本次查询的快照，点击刷新获取最新数据。

管理功能只允许管理员私聊。群组仅接收指定通知；通知接收人不会自动获得管理权限。

## IP / DDNS 通知

消息显示节点名称、旧 IP、新 IP、域名、DDNS 同步结果和近期 IP 更换次数：

```text
🌐 节点 IP 已更换
━━━━━━━━━━━━━━
节点  日本节点
IPv4  1.1.1.1 → 2.2.2.2
域名  jp.example.com
DDNS  ✅ 已自动同步
━━━━━━━━━━━━━━
📊 该节点近 7 天已更换 3 次 IP
```

首次发现地址建立基线，不计为更换；同一轮 IPv4、IPv6 同时变化计一次。DDNS 失败后恢复会单独发送同步结果，不增加 IP 更换次数。配置新的通知目标后，只发送后续事件。

启用 DDNS 的节点直接使用 DDNS 检测结果。节点更新到 v0.17.3 后，未启用 DDNS 时也能每分钟检测公网 IP，消息中显示「DDNS 未启用」。
