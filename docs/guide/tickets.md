# 工单

用户在「工单」点击「发起工单」，填写标题、低/中/高优先级和问题描述。标题最多 128 字，正文或回复最多 5000 字，均为纯文本。

创建时使用「系统设置」的人机验证方式。选择图形验证码时必须完成验证；即使站点关闭注册，已登录用户仍可创建工单。

用户只可查看和回复自己的工单。管理员在「工单管理」处理全部工单，作为客服回复：

| 优先级 | 后台标识 |
| --- | --- |
| 低 | 淡蓝色 |
| 中 | 淡黄色 |
| 高 | 淡红色 |

用户发消息后状态为「等待客服」，客服回复后为「等待用户」。双方都可关闭或重新打开工单；关闭期间不能回复。

列表和打开的对话会自动刷新，较长对话支持翻页。当前不支持图片和附件。
