# 自动换 IP

在「节点管理」点击节点旁的「自动换 IP」。节点每 **5 秒** ping 一次配置的国内公网 IPv4，连续失败达到设置次数后，调用小助理 API 更换实例 IP；成功 ping 会清零失败次数。

## 配置

| 配置项 | 用途 |
| --- | --- |
| 启用自动换 IP | 开关该节点的检测与自动换 IP；关闭后保留配置 |
| 国内检测 IPv4 | 指定可响应 ping 的国内公网 IP |
| 连续失败次数 | 默认 6 次，可设置 1–720 次 |
| 冷却时间 | 默认 300 秒，从最近请求或成功 IP 变化开始计时 |
| 实例类型 | EC2 或 Lightsail |
| 绑定方式 | 固定实例 ID，或跟随档案 ID |
| 认证 Token | 小助理的 `X-Auth-Token` |
| 分享组 Token | 使用分享凭证时填写；与认证 Token 至少填写一个 |
| 小助理账号 ID | 固定实例模式填写 `X-Account-Id`；使用分享凭证时可留空 |
| 地区 | 固定实例模式填写 `X-Region-Name`，例如 `ap-southeast-1` |
| 实例标识 | 固定实例模式中，EC2 填实例 ID，Lightsail 填实例名称 |
| 实例档案 ID | 档案模式填写小助理的档案 `id`，自动查询当前实例、账号与地区 |
| 新 IP 类型 | 动态或静态 IP |

保存后由主控下发。检测和小助理请求在节点上执行，节点使用缓存配置，可在主控断线期间继续运行。节点需要新版程序及 ICMP 权限；新版节点安装脚本会配置 systemd 权限。

使用自动补机的机器选择「跟随档案 ID」。只要小助理沿用同一档案，补机后无需修改实例 ID；支持认证 Token 或分享组 Token。分享页面按 F12 打开网络面板，刷新后查看 `ec2-instance-profiles`（Lightsail 为 `lightsail-instance-profiles`）请求，对应记录的 `id` 即档案 ID，分享链接中的 `sgt` 是分享凭证。

档案暂未关联可用实例时自动重试。换 IP 期间若档案切换到新实例，停止关联旧任务，保留冷却后重新检测。新机器仍通过开机脚本安装节点。档案模式需要支持此功能的新版节点；旧节点升级前不会执行该模式的换 IP。

## 状态

页面显示 ping 结果、连续失败次数、换 IP 进度、冷却时间、新旧 IP 及最近解析的实例和地区。一次换 IP 完成前不重复提交请求；节点重启后先查询已提交任务的结果。

确认公网 IP 变化后，节点立即检查 DDNS；IP / DDNS 通知沿用 [Telegram Bot](./telegram.md) 配置。小助理自身的 GFW 检测不会开启。

请求结果长期待确认时，先查看小助理任务，任务结束后点击「重置等待状态」。重置保留冷却时间，重新累计失败次数。
