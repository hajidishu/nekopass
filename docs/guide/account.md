# 注册与邀请

## 注册与登录

站点开放注册时，登录页显示「注册账号」。填写邮箱和两次密码；开启邮件验证时还需填写邮件验证码。邮箱就是登录用户名。密码为 12–72 字节，邮箱登录不区分大小写。

站点采用图形验证码时，开启邮件验证则在发送邮件前填写图片数字，关闭邮件验证则在提交注册前填写。邮件验证码有效期 10 分钟，最多尝试 5 次，重新发送需等待 60 秒。注册成功后返回登录页。用户忘记密码时由管理员在「用户管理」修改；管理员密码恢复见 [日常管理](./manage.md#重置管理员密码)。

如果配置了用户条款或隐私条款，注册页显示相应链接，用户勾选同意后完成注册。强制邀请开启时，填写有效的老用户邀请码；未开启时，邀请码可选。

关闭注册时，由管理员创建账号。新注册账号不会自动获得套餐，登录后可在 [商城](./shop.md) 购买，或由管理员分配。

## 保持登录

默认长期保持登录：服务端会话没有固定过期时间，浏览器 Cookie 有效期 365 天，访问时每天最多自动续期一次。关闭浏览器、正常重启或升级面板不会主动退出；不同设备互不影响，也不绑定 IP。

退出登录撤销当前会话；修改密码或停用账号撤销全部会话。管理员在「用户管理」点击「强制退出」可退出该用户的所有设备，用户之后仍可重新登录。

## 管理员设置

「系统设置」可分别开关注册和注册邮件验证、选择人机验证方式，并设置条款 URL。邮件验证默认开启；关闭后不要求邮件验证码，也不将新账号的邮箱标记为已验证。人机验证仍用于注册和工单创建；关闭注册不影响已登录用户发起工单。

开启注册邮件验证前填写 SMTP 主机、端口、连接方式、用户名、密码/授权码、发件邮箱和发件名称；关闭邮件验证时可不配置 SMTP。支持 STARTTLS、TLS、明文连接；远程明文中继不支持密码认证，通常选择 STARTTLS（587）或 TLS（465）。

强制邀请默认关闭，须先启用邀请返利。关闭全局返利时，应同时关闭强制邀请。

## 邀请返利

用户在「邀请返利」复制邀请码或链接。链接形式为 `/register?code=邀请码`，注册页自动填入；有效邀请关系在注册时绑定。

| 模式 | 规则 |
| --- | --- |
| 首次返利 | 被邀请用户的第一笔大于 0 元的成功套餐购买或续费返利。 |
| 循环返利 | 每笔大于 0 元的成功套餐购买和续费均返利。 |

充值和免费套餐不返利，也不占首次机会。返利按实付金额计算到分，小于 1 分的部分舍去，直接增加邀请人的余额，并作为「邀请返利」订单显示。

管理员在「系统设置」设置全局开关、类型和比例；在「用户管理 → 编辑」可单独开关、选择类型或设置比例。个人设置可跟随系统，比例留空继承系统值，填 `0` 表示零返利；全局关闭时个人开启不生效。

站点未启用返利时，用户页显示「此站点未开启邀请返利功能」。
