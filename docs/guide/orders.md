# 订单查询

## 用户订单

「我的订单」显示当前账号的套餐购买、续费、充值和邀请返利。返利以正数收入显示，待支付充值可继续付款。

点击订单号查看详情。套餐订单中的到期时间和下次重置时间是购买时的记录，之后续费或管理员修改不会改写历史订单。

## 管理员查询

「管理后台 → 订单查询」可查询所有用户的订单。点击「筛选」组合条件：

| 条件 | 用途 |
| --- | --- |
| 订单号 | 完整或部分面板订单号。 |
| 用户邮箱 / 用户名 | 完整或部分邮箱，也适用于旧用户名。 |
| 用户 ID | 精确查找某个用户。 |
| 订单类型 | 套餐购买、续费、充值或邀请返利。 |
| 订单状态 | 已完成、待支付或已取消。 |
| 时间依据与范围 | 按创建或完成时间筛选。 |
| 支付平台流水号 | 查找网关交易，支持部分流水号。 |

分页保留当前条件；「清除筛选」恢复全部订单。点击订单号查看金额、用户、时间、支付流水、备注及相关历史信息。

「用户管理 → 查询订单」自动按用户 ID 筛选，账号改名后仍然有效。订单查询为只读，不会修改支付状态或余额。
