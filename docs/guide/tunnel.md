# 节点中转

## 关联入口与出口

在节点编辑中点击「编辑传输协议」，分别选择传输协议和安全性。用于中转出口时，开启「作为出口节点」，填写隧道地址、监听端口与允许使用它的入口。

传输协议可选 raw(tcp)、h2、raw(udp)。raw(tcp) 和 h2 支持 TCP、UDP，可搭配明文或 TLS；raw(udp) 仅支持 UDP，可搭配明文或 DTLS。配置属于出口，入口按规则所选出口连接。

用户创建规则时选择入口和出口。用户当前个人节点组设置需同时授权入口与出口，套餐只提供初始授权。

- 专用出口：关闭「允许作为入口」。
- 强制中转：在入口关闭「允许用户选择直转」；已有直转规则需先修改出口。

## 协议

| 协议 | 配置 |
| --- | --- |
| [raw(tcp)](../protocols/plain-tcp.md) | 出口地址与监听端口，可搭配不加密或 TLS |
| [h2](../protocols/h2.md) | HTTP Host、Path、连接池与流控，可搭配不加密或 TLS |
| [raw(udp)](../protocols/raw-udp.md) | 原生 UDP 传输，可搭配不加密或 DTLS |

raw(tcp) + TLS 和 h2 + 不加密需要两端升级至 v0.15.0 或以上。当前默认目标 IP 限制需要节点 v0.15.2 或以上。出口监听端口必须对入口可达。

UDP 转发需要主控及相关节点 v0.17.0 或以上，配置与限制见 [UDP 转发](../protocols/udp.md)。
