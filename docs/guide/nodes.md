# 节点与节点组

## 基本配置

「节点管理 → 编辑」设置名称、公网入口地址、节点密钥、所属组、端口范围、连接限制和探针。密钥留空保存会生成新值；已安装节点更换密钥后需更新其连接配置并重启。

公网地址是用户连接的入口域名或 IP，不是主控地址。出口配置中的隧道对外地址是入口连接出口的位置，也不填写主控地址。

入口和出口可同时启用。在节点编辑主窗口设置入口权限、是否允许直转、出口地址和关联入口；安全性及证书参数在旁边的「安全性设置」窗口配置；「编辑传输协议」子窗口只设置传输协议及其参数，详见 [节点中转](./tunnel.md)。配置统一由主控下发。

## 流量倍率

节点编辑主窗口分别设置「入口流量倍率」与「出口流量倍率」，支持 `0–1000`，最多四位小数。默认入口 `1` 倍、出口 `0` 倍。

```text
消耗额度 = 实际传输流量 × 入口倍率 + 实际传输流量 × 出口倍率
```

实际流量按双向业务数据合计。直转只计算入口倍率；选择出口组时，按该连接实际选中的出口倍率计算。例如传输 10 GiB、入口 1 倍、出口 0.5 倍，消耗 15 GiB 额度。

合计 0 倍的线路不消耗额度，额度耗尽后仍可使用，账号和套餐需保持有效；带宽、IP 和连接数限制仍生效。组内同时有免费和收费出口时，额度耗尽后只使用免费成员。

规则统计显示实际流量，个人中心分别显示实际传输流量与已消耗额度。修改倍率仅影响同步后的转发，不追溯重算历史用量。计费以字节为单位累计小数，向上取整。

自定义倍率需要升级入口节点；旧节点仅支持合计 1 倍的线路，其他倍率规则显示需要升级。

## 节点组

在「节点组管理」创建组并添加节点，再通过套餐初始授权或用户个人设置授予访问权限。一个节点可加入多个组；未获授权的节点不能用于规则。

调整组内成员会影响已授权该组的用户；修改套餐的节点组列表不会覆盖已有用户的个人授权。

节点组也可以作为规则的出口。在组编辑窗口选择加权最少连接、加权轮询或加权随机，并设置成员的出口职责与权重：

| 职责 | 行为 |
| --- | --- |
| 正常出口 | 参与日常转发，权重越高分配比例越高。 |
| 容灾备用 | 正常出口全部不可用时接收新连接。 |
| 不参与出口转发 | 保留成员及访问权限，不参与本组的出口调度。 |

职责按组保存，同一节点可在不同组中承担不同职责。成员还需启用出口、关联对应入口，并支持规则的 TCP / UDP 类型。

入口通过实际隧道协议进行鉴权探测，默认每 5 秒检查一次，连续失败 3 次停用候选，连续成功 2 次恢复。探测间隔及失败、恢复次数可在组内修改。正常出口恢复后，新连接切回正常出口；TCP 连接和 UDP 会话固定使用建立时选中的出口。

用户「节点状态」按获授权的组展示探针，不显示节点 IP。可查看 CPU、内存、磁盘、网卡收发 Mbps、系统网络连接数和负载；这些网卡速率是服务器流量，不等于用户套餐的已用业务流量。

探针设置包括采样间隔（2–60 秒）、磁盘路径及网卡。网卡留空时优先选择默认路由网卡，也可每行填写一个接口名。

## 节点状态探针

「节点状态」显示 CPU、内存和硬盘占用、网络速率、连接数、负载、主磁盘读写速率，以及最后上报、首次上线和系统已运行时间。主磁盘 I/O 对应所监测挂载点的磁盘，默认根目录，使用 MB/s 或 GB/s。

今日与近 30 天流量分别显示上传、下载，按 UTC+8 自然日统计，近 30 天包含当天。统计使用探针所选网卡的实际收发字节，与用户套餐计费独立；默认监测默认路由网卡。历史从升级后开始记录，重启不会清空；跨日采样按时间比例分配流量。

CPU、内存和硬盘直接显示使用率趋势图，磁盘 I/O 在同一张图中显示读取、写入两条曲线；保留最近最多 120 个采样点，随节点上报更新。首次上线时间在主控第一次记录该节点连接时保存，后续重连不改写；旧节点从升级后的首次连接开始记录。

## DDNS

自动检测国内 IP 连通性并调用小助理换 IP，见 [自动换 IP](./ip-recovery.md)。配置入口也在节点列表的操作按钮中。

在节点列表的「安装命令」「编辑」旁点击「DDNS」。当前支持 Cloudflare，由节点获取 IP 并创建或更新 A / AAAA 记录，使用仅 DNS 模式。

| 设置 | 用途 |
| --- | --- |
| 记录域名 | 完整域名，不含协议、端口或通配符。 |
| API Token | 需要所在区域的 DNS 编辑权限。 |
| Zone ID | 可留空自动识别，此时 Token 还需 Zone 读取权限。 |
| IP 类型 | 至少选择 IPv4 或 IPv6。 |
| IP 获取方式 | 默认通过公网 API 查询，也可选择从节点已启用的网卡获取。 |
| 忽略内网 IP 和回环地址 | 仅网卡方式显示，默认勾选；取消后允许使用内网或回环地址。 |
| 检查间隔 | 默认 300 秒，可填 60–86400。 |
| DNS TTL | 默认 300 秒，`1` 为自动，其余 60–86400。 |
| IP 获取地址 | 仅公网 API 方式显示，填写返回纯文本公网 IP 的 HTTPS 地址，可分别配置 IPv4 / IPv6。 |
| 使用此域名 | 可同时或分别替换节点公网地址、隧道出口地址。 |

网卡方式优先选择公网地址，其次为内网地址，最后为回环地址；同类地址按 IP 排序选择。每个 IP 类型使用一个地址，链路本地地址不参与选择。NAT 后的服务器可使用公网 API 获取其公网出口地址。

获取 IPv4 / IPv6 失败时，间隔 1 秒重试，最多尝试 3 次；三次均失败才上报错误，已开启的 Telegram 通知随后发送失败消息。

同步结果与「立即更新」都在 DDNS 页。停用后停止更新，已有记录和节点地址保留。DDNS 不修改 TLS 的 SNI 或证书；证书域名仍需单独配置。

## 删除节点

先停用节点，并迁移或删除把它用作入口或出口的转发规则。在线节点需同步停用配置；离线或已卸载的节点无需等待同步。

存在历史用量或额度授权时，面板会再次确认是否强制删除。确认后移除节点及密钥，原属于当前周期的已用流量和额度占用保持不变，已下发但未归还的额度不会因删除返还。
