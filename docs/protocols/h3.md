# HTTP/3

使用 QUIC 上的真实 HTTP/3 连接，同时承载 TCP 与 UDP 转发。TCP 使用 CONNECT 双向流；UDP 使用 CONNECT-UDP 数据报，同一入口通过连接池复用到出口的 QUIC 连接。

HTTP/3 **固定使用 TLS 1.3**。在出口节点「编辑传输协议」选择 HTTP/3，然后在「安全性设置」配置证书、SNI 和 Fallback。

## 配置项

| 配置项 | 用途 |
| --- | --- |
| 隧道对外地址 | 入口能够访问的出口域名或 IP。 |
| 出口监听地址、端口 | 出口同时监听此端口的 TCP 和 UDP，分别提供 HTTPS 与 HTTP/3。 |
| 公网隧道端口 | 端口映射后的端口；`0` 使用监听端口。TCP 与 UDP 使用同一个公网端口。 |
| UDP HTTP Host | CONNECT-UDP 使用的 HTTP 域名，可带端口；留空使用证书域名。 |
| UDP 路径前缀 | 默认 `/api/stream`；CONNECT-UDP 在此路径后附加目标地址和端口。TCP CONNECT 不使用此配置。 |
| 连接池上限 | 每个入口连接此出口的 QUIC 连接数上限，多个用户规则共享；默认 `2`，范围 `1–8`。 |
| 每流接收窗口 | 每条 TCP 流的接收窗口上限；默认 `16 MiB`，范围 `1–64 MiB`。 |
| 每连接接收窗口 | 每个 QUIC 连接的接收窗口上限；默认 `64 MiB`，不小于每流窗口，最大 `256 MiB`。 |
| 每连接并发流 | 一个 QUIC 连接同时承载的转发流上限；默认 `256`，范围 `1–1024`。 |
| 安全性 | 固定 TLS；支持自签名、导入、HTTP 或 DNS 自动申请证书，见 [TLS](../security/tls.md)。 |
| HTTP/3 Padding | 在安全性设置中开启，使用标准 QUIC 填充；入口与出口由主控统一下发配置。 |
| 单包最多填充 | 每个包额外填充的字节上限，默认 `1400`，范围 `1–1400`；实际不超过路径 MTU。 |
| 突发填充预算 | 每条 QUIC 连接每个发送方向可用的填充预算，默认 `8192` 字节，最大 `65536`，不小于单包上限。 |
| 预算补充速率 | 每秒补充的填充预算，默认 `8192` 字节/秒，范围 `1–65536`。 |
| Fallback 网站地址 | 普通访问和未通过隧道认证的 HTTP 请求反向代理到此 HTTP / HTTPS 网站；留空或网站不可用时返回普通 404。 |
| 允许哪些入口使用此出口 | 选择允许接入的入口；用户还需获得入口、出口的节点组权限。 |

## 使用

1. 将面板、入口与出口更新到支持 HTTP/3 的版本。
2. 在出口选择 HTTP/3，填写对外地址、端口及允许的入口，配置 TLS 证书与 Fallback 后保存下发。
3. 出口防火墙和安全组放行隧道端口的 **TCP 和 UDP**。
4. 用户创建 TCP 或 UDP 规则，选择该出口；也可选包含该出口的节点组。

浏览器访问出口的 HTTPS 地址会显示 Fallback 网站，服务器通过 `Alt-Svc` 声明同一端口的 HTTP/3 服务。

TCP 流各自使用 QUIC 的可靠传输。UDP 保留数据报边界，不通过可靠 TCP 流传输；较大的 UDP 数据报使用标准 Datagram Capsule，经各自的 QUIC 流传输。用户流量只统计业务数据，HTTP/3、QUIC 和 TLS 开销不计入套餐用量。

HTTP/3 Padding 按连接和业务负载调整填充，不需要填写 AnyTLS 策略；不会主动延迟业务数据，也不生成额外的数据包。启用后入口、出口均需升级到支持此选项的节点版本。
