# h2

使用真实 HTTP/2 双向流，将多条转发连接复用到有限的物理连接。可搭配不加密（h2c）或 TLS。

| 配置项 | 用途 |
| --- | --- |
| 出口传输协议 | 选择 h2。 |
| 安全性 | 不加密使用 h2c；TLS 使用 HTTP/2 over TLS。 |
| 隧道对外地址 | 入口能访问的出口域名或 IP。 |
| 出口监听地址、端口 | 出口节点实际监听的位置。 |
| 公网隧道端口 | NAT / TCP 透传时入口连接的公网端口；0 使用监听端口。 |
| HTTP Host | 请求使用的域名；TLS 模式留空使用证书域名，不加密留空使用出口地址。 |
| HTTP Path | 隧道请求路径，入口与出口使用同一配置。 |
| Fallback 网站地址 | 未认证或 Host、Path 不匹配时反向代理的网站；留空或不可用时返回普通 404。 |
| 连接池上限 | 每个入口连接此出口的物理连接数上限，按需创建。 |
| 每流接收窗口 | 入口接收出口数据时，每条 HTTP/2 流的窗口。 |
| 每连接接收窗口 | HTTP/2 连接的总接收窗口。 |
| 每连接并发流 | 一个出口连接同时承载的转发流上限。 |
| 允许哪些入口使用此出口 | 允许接入的入口节点；用户还需获得两端的节点组权限。 |

选择 TLS 时显示 [TLS 设置](./tls.md)。不加密模式仍校验隧道认证和规则权限，但网络中的请求与转发数据为明文。
