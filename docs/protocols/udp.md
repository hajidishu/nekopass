# UDP 转发

添加规则时选择 **UDP** 或 **TCP+UDP**。旧规则和未指定类型的旧备份默认 TCP。TCP 和 UDP 可使用同一个数字端口；TCP+UDP 同时占用两种协议的端口。

| 出口选择 | 数据路径 |
| --- | --- |
| 不使用隧道，直接转发 | 客户端 → 入口 → UDP 目标 |
| raw(tcp) | 将 UDP 数据报封装进 TCP；可选明文或 TLS |
| h2 | 将 UDP 数据报封装进 HTTP/2 双向流；可选明文或 TLS |
| raw(udp) | 原生 UDP 隧道；可选明文或 DTLS |

UDP 需要面板及入口、出口节点均升级至 v0.17.0；旧节点不会启用 UDP 规则。raw(udp) 不支持 TCP 或 TCP+UDP 规则。

每个客户端地址、端口与规则建立独立会话，同一会话固定目标。管理员在节点基本设置调整「UDP 会话空闲超时」，默认 60 秒，范围 10–3600 秒。连接数限制也计入 UDP 会话；用户限速仍按每个入口节点双向共享。

流量只统计入口实际转发的业务载荷，不计隧道头、加密或控制报文；出口不重复统计。UDP 包不会按剩余额度截成半包，额度不足时丢弃并结束会话。暂停、额度周期变化和权限撤销会清理会话。

UDP 暂不支持 Proxy Protocol；nyanpass 兼容导出不包含 UDP 类型，请使用 Nekopass 完整备份。TCP/h2 隧道保留 UDP 包边界，但经过 TCP 重传，丢包时可能增加延迟。
