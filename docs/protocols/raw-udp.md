# raw(udp)

在出口「编辑传输协议」选择 **raw(udp)**，在旁边的「安全性设置」选择「不加密」、「TLS」或「全随机加密」。只承载 UDP 业务。

| 配置项 | 用途 |
| --- | --- |
| 隧道对外地址 | 入口可访问的出口地址 |
| 出口监听地址、端口 | 绑定出口的 UDP 监听端口，防火墙须放行 UDP |
| 公网隧道端口 | NAT 对外的 UDP 端口；0 使用监听端口 |
| 允许的入口 | 允许接入的入口节点，仍需用户拥有两端节点权限 |
| 安全性 | 明文、[TLS](../security/tls.md) 或 [全随机加密](../security/random.md) |

面板及入口、出口节点使用 v0.17.1 或以上。隧道通过节点间密钥与来源地址挑战建立会话，双向独立认证，并校验数据包序号。

大包在隧道内分片，支持乱序重组并保留原始包边界。节点统一管理接收缓存，会话空闲超时在节点基本设置中调整。

选择「TLS」后，在出口填写证书相关设置，详见 [TLS](../security/tls.md)。

选择「全随机加密」时，填写算法和密钥（留空自动生成），入口和出口均需使用支持此组合的节点版本。节点间加密会话可复用，用户和规则的 UDP 会话独立管理；不使用证书。隧道包控制在 1200 字节以内，仅握手和建连控制消息有限重试，业务数据不自动重传。
