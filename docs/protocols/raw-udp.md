# raw(udp)

在出口「编辑传输协议」选择 **raw(udp)**，安全性选择「不加密」或「TLS（DTLS）」。只承载 UDP 业务。

| 配置项 | 用途 |
| --- | --- |
| 隧道对外地址 | 入口可访问的出口地址 |
| 出口监听地址、端口 | 绑定出口的 UDP 监听端口，防火墙须放行 UDP |
| 公网隧道端口 | NAT 对外的 UDP 端口；0 使用监听端口 |
| 允许的入口 | 允许接入的入口节点，仍需用户拥有两端节点权限 |
| 安全性 | 明文或 [DTLS](../security/dtls.md) |

隧道使用节点间独立密钥认证，无效或未认证的数据包静默丢弃。建立会话前验证来源地址挑战，避免凭一份重放请求向任意地址发送大量回复；数据包有序号和重放窗口。

大包在隧道内分片，乱序重组保留原始包边界。丢失分片时丢弃整包，不自动重传；分片缓存有大小和超时限制。普通 UDP 转发服务仍面向客户端接收数据，不能保证客户端源地址没有被伪造。

此协议不使用 HTTP Host、Path、网页 Fallback 或 uTLS 指纹。无效请求静默丢弃能减少主动探测信息，但不等于流量不可识别；明文业务载荷可被读取，DTLS 也保留长度、时序及连接特征。
