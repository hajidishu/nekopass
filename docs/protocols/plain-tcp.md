# 明文 TCP 中转

客户端连接入口，入口通过明文 TCP 隧道连接出口，再由出口连接目标。入口与出口之间的数据不由本协议加密。

## 出口节点配置

在「节点管理 → 编辑 → 编辑传输协议」中设置：

| 配置项 | 用途 |
| --- | --- |
| 作为出口节点 | 开启后该节点可承接入口转来的连接。 |
| 传输协议 | 选择「明文 TCP」（`plain_tcp`）；此选择在「作为出口节点」开关上方，选择后隐藏 tls+h2 专用配置。 |
| 隧道对外地址 | 入口实际连接的出口域名或 IP，不带协议和端口；动态 IP 可通过节点列表的「DDNS」绑定域名。 |
| 出口监听地址 | 出口在本机绑定的 IP；默认 `0.0.0.0`。 |
| 出口监听端口 | 接收隧道连接的端口，范围 `1–65535`；须对入口开放。入口使用这个端口，NAT 需将同号公网端口转发到它。 |
| 允许哪些入口使用此出口 | 选择获准使用该出口的入口节点；未关联的入口不能使用。 |
| 允许作为入口 | 此节点是否也可接收用户连接；专用出口可关闭。 |
| 目标建连超时 / 秒 | 出口连接目标时的等待上限，默认 `8`。 |
| 启用节点 | 控制该节点的转发是否运行。 |

节点总连接数、规则监听端口范围等通用选项见 [TCP 直转的节点配置](./tcp.md#管理员节点配置)。TLS 证书、SNI、指纹和 HTTP2 流控不作用于明文 TCP 中转。

## 入口与规则配置

| 配置项 | 用途 |
| --- | --- |
| 允许作为入口 | 在入口节点开启，使用户可以选用它。 |
| 允许用户选择直转 | 开启时用户也可不选出口；关闭后规则必须使用已关联的出口。 |
| 规则入口 | 接收用户连接的节点。 |
| 规则出口 | 选择关联的明文 TCP 出口；套餐须同时授权两者所属节点组。 |
| 规则监听端口 | 用户连接入口的业务端口，与出口的隧道监听端口不同。 |
| 目标地址 | 由出口访问的最终服务地址，须从出口可达。 |

名称、分组、目标负载均衡、Proxy Protocol 和套餐限制的用途见 [规则配置](./tcp.md#规则配置)，在此协议下含义相同。
