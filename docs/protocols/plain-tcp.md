# raw(tcp)

客户端 → 入口 → 出口 → 目标。默认每条转发连接对应一条入口到出口的连接，可搭配不加密、TLS 或全随机加密。

开启 Mux 后，多条业务连接共享入口到出口的 TCP 连接。TCP 业务与 UDP 业务分别使用连接池，用户客户端无需额外设置。

| 配置项 | 用途 |
| --- | --- |
| 出口传输协议 | 选择 raw(tcp)。 |
| 安全性 | 不加密使用明文 TCP；TLS 使用加密 TCP；全随机加密使用所选 AEAD 算法。 |
| 隧道对外地址 | 入口能访问的出口域名或 IP。 |
| 出口监听地址、端口 | 出口节点实际监听的位置。 |
| 公网隧道端口 | NAT / TCP 透传时入口连接的公网端口；0 使用监听端口。 |
| 允许哪些入口使用此出口 | 允许接入的入口节点；用户当前个人设置还需获得两端的节点组权限。 |

安全性选择见 [不加密](../security/none.md) 、[TLS](../security/tls.md) 和 [全随机加密](../security/random.md)。raw(tcp) 不使用 HTTP Host、Path 或 HTTP/2 连接池。搭配 TLS 时，可在「安全性设置」窗口配置普通 HTTP 访问的 Fallback 网站。

## Mux 多路复用

在出口「编辑传输协议」中配置，默认关闭。入口与出口都更新到支持 Mux 的节点版本后生效。

| 配置项 | 用途 |
| --- | --- |
| 启用 Mux | 使用 Yamux，将多条 TCP 连接或 UDP 会话复用到节点间连接。 |
| 每连接最大子会话数 | 默认 128，范围 1–4096；达到上限后按需建立新的承载连接。 |
| 底层连接数量上限 | 默认留空不限制，最多填写 1024；按入口、出口和业务类型分别计算。 |
| 空闲回收时间 | 无业务的承载连接多久后关闭，默认 60 秒，范围 10–3600 秒。 |

TLS Padding 在共享承载连接上生效。流量、限速、IP 和连接数限制继续按各业务连接或会话计算，Mux 控制消息不计入套餐流量。节点组按实际选中的出口分别建池。
