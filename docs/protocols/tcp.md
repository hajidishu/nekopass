# TCP 直转

客户端连接入口节点的规则端口，由入口直接连接目标。规则出口选择「不使用隧道，直接转发」；管理员须开启该入口的「允许用户选择直转」。

## 规则配置

| 配置项 | 用途 |
| --- | --- |
| 名称 | 规则显示名称；留空使用第一个目标地址。 |
| 入口 | 接收客户端连接的节点，须在套餐授权范围内。 |
| 出口 | 选择「不使用隧道，直接转发」。 |
| 监听端口 | 客户端连接的端口，须在节点可分配范围内；留空或 `0` 自动分配。 |
| 目标地址 | 实际连接的服务，一行一个，最多 32 个。格式为 `域名:端口`、`IPv4:端口` 或 `[IPv6]:端口`。 |
| 负载均衡策略 | 多目标时决定新连接使用哪个目标：随机、依次轮询或选择当前连接最少的目标。 |
| 接受 Proxy Protocol | 读取上游代理传来的原始客户端地址；上游需要发送该协议头。普通客户端连接保持关闭。 |
| 信任代理网段 | 开启接受 Proxy Protocol 后指定可信上游来源；一行一个 CIDR，例如 `192.0.2.0/24`。 |
| 发送 Proxy Protocol | 向目标发送原始客户端地址；目标服务需要支持并启用 Proxy Protocol。 |
| 分组 | 将规则归入用户自己的分组，便于筛选和批量操作。 |
| 启用 / 暂停 | 控制该规则是否接收和转发连接。 |

规则限速、IP 上限和连接数上限由套餐统一控制，在规则页查看。

## 管理员节点配置

| 配置项 | 用途 / 默认值 |
| --- | --- |
| 节点公网地址 | 展示给用户的入口地址，填写客户端可访问的域名或 IP。 |
| 允许作为入口 | 开启后可供用户选作入口；关闭后不能新建使用它作为入口的规则。 |
| 允许用户选择直转 | 开启后用户可以选择不经过出口节点。 |
| 监听地址 | 规则端口绑定的本机 IP；默认 `0.0.0.0`，监听所有 IPv4 地址。 |
| 可分配端口起始 / 结束 | 限定规则可用的端口范围，默认 `1024–65535`。 |
| 节点总连接数上限 | 限制整个节点的并发转发连接，默认 `10000`；留空不限制。 |
| 目标建连超时 / 秒 | 建立连接时最多等待多久，默认 `8`，可填 `1–120`。 |
| 空闲连接超时 / 秒 | 双向持续没有业务数据时关闭连接，默认 `300`，可填 `10–86400`。 |
| 启用节点 | 停用会关闭此节点的转发，保留主控连接及探针。 |

本模式不新增隧道加密，业务本身使用 HTTPS 等加密时仍保持其原有加密。
