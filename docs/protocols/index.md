# 传输协议

目前支持 TCP 业务。用户在规则中选择入口和出口，管理员在节点编辑的「传输协议」中配置出口协议。

| 方式 | 数据路径 | 配置说明 |
| --- | --- | --- |
| TCP 直转 | 客户端 → 入口 → 目标 | [TCP 直转](./tcp.md)；规则出口选择「不使用隧道，直接转发」 |
| 明文 TCP 中转 | 客户端 → 入口 → 出口 → 目标 | [明文 TCP](./plain-tcp.md)；出口协议选择「明文 TCP」 |
| tls+h2 | 客户端 → 入口 → 加密隧道 → 出口 → 目标 | [tls+h2](./tls-h2.md)；出口协议选择「tls+h2」 |

每个协议页分别列出规则选项、节点设置或证书与流控配置。节点关联与套餐授权见 [节点中转](../guide/tunnel.md)。
