# TLS 安全设置

raw(tcp) 和 h2 都可选择 TLS。配置属于出口，连接它的入口使用同一组设置。

| 配置项 | 用途 |
| --- | --- |
| 证书域名 / SNI | 证书覆盖的域名。 |
| 连接 SNI | 入口发送的 SNI，留空使用证书域名；必须通过证书校验。 |
| uTLS 指纹 | 关闭使用标准 TLS；Chrome、Firefox 使用库内预设。 |
| 证书模式：自签名 | 自动生成证书，入口由主控下发的公开证书验证。 |
| 证书模式：手动导入 | 填写证书链和匹配私钥；私有 CA 可填写公开根证书。 |
| 证书模式：DNS 自动申请 | 使用 DNS 服务商凭据完成验证并自动续期。 |
| 证书模式：HTTP 自动申请 | 出口开放 HTTP 验证服务；CA 从公网 80 端口验证。 |
| ACME 邮箱、Directory | 自动申请使用的邮箱和 CA 接口地址。 |
| HTTP 验证监听端口 | 出口本地验证端口；不是 80 时需配置公网 80 到该端口的转发。 |
| DNS 服务商、凭据 JSON | DNS 自动申请所用的服务商及授权信息，仅由主控使用。 |
| ACME 私有根 CA | 私有 ACME 服务的公开根证书；公共 CA 留空。 |
| 签发根 CA | 私有签发 CA 的公开根证书，供入口验证；公共 CA 留空。 |

h2 的 Host、Path、Fallback 和流控设置见 [h2](./h2.md)。HTTPS Fallback 可接管部分握手早期失败的连接；TLS 握手已经发出失败告警后不能再返回网页。
