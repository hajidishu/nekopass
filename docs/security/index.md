# 安全性

在「节点管理 → 编辑 → 编辑传输协议」的出口配置中选择安全性，与 [传输协议](../protocols/index.md) 独立搭配。

| 安全性 | 说明 | 支持的传输协议 |
| --- | --- | --- |
| [不加密](./none.md) | 明文传输，仍校验隧道身份和规则权限 | raw(tcp)、h2、raw(udp) |
| [TLS](./tls.md) | 加密入口到出口的连接，统一配置证书与 SNI | raw(tcp)、h2、raw(udp) |

各加密方式的配置说明统一放在本节，后续新增方式也归入这里。节点到主控的连接见 [安装节点](../guide/node.md#密钥与连接)。
