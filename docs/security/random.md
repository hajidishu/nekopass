# 全随机加密

加密入口到出口的隧道连接，可搭配 **raw(tcp)**、**h2** 或 **raw(udp)**，两端均需使用支持此功能的节点版本。

在「节点管理 → 编辑 → 安全性设置」选择「全随机加密」，设置后返回主窗口「保存并下发」。

| 配置项 | 用途 |
| --- | --- |
| 加密算法 | ChaCha20-Poly1305 或 AES-256-GCM，默认 ChaCha20-Poly1305。 |
| 加密密钥 | 32 字节 Base64 密钥；留空自动生成，已填写则保存该密钥。 |

配置属于出口，主控将所选算法和密钥下发给关联入口，无需手动配置节点文件。h2 的 Host、Path、连接池和流控参数仍在「编辑传输协议」中设置。

此模式无需证书或 SNI，身份、握手和传输数据经过认证加密，不提供 Padding。raw(tcp) 和 h2 可承载 TCP、UDP 转发；raw(udp) 只承载 UDP 转发。

raw(udp) 使用节点间复用的加密会话，逐包独立认证，支持乱序接收和重放拦截；大包自动分片、重组，丢包不阻塞后续数据包。来源地址变化或会话失效后，会重新握手。
